# Primeva

**A Thaumcraft-inspired magic mod for NeoForge 1.21.1.** Perceive the six primal essences hidden in everything, research forbidden knowledge, distill and brew in the crucible, perform unstable infusion rituals and command arcane golems, all while keeping your mind from breaking.

| | |
|---|---|
| Minecraft | 1.21.1 |
| Loader | NeoForge 21.1.259+ |
| Java | 21 |
| Side | Client **and** server |
| Optional | JEI (recipe categories for infusion and crucible) |

## Features

- **Six essences**: Ember, Lumen, Gale, Tide, Terra and Umbra, linked in the Primal Cycle.
- **Grimoire** with research tree, lore pages, recipe pages and a full in-game **Guide** tab.
- **Research minigame**: link anchor essences on a hex board through the Cycle.
- **Distiller, jars, tubes and filter tubes** to extract and move essence.
- **Arcane Crucible** alchemy with catalysts.
- **Infusion rituals** on an altar with pedestals, essence drain, growing instability and collapses.
- **Miasma** that corrupts the land, spawns wraiths and must be purified.
- **Corrupted Mind**: forbidden knowledge brings whispers, visions, wraiths and nightmares.
- **Wands and foci**, elemental tools, armor sets with set bonuses, trinkets, bows and essence arrows.
- **Arcane golems** with seals, filters and cores.
- **Crimson Cult** enemies and the Crimson Herald boss.
- World generation: Vermilion and Amber ores, essence crystals, Argent and Elder trees, Corruption Sites.

## Download

## Building

```
./gradlew build
```

The build expects the JEI jar in `libs/` (see `libs/README.txt`). The output is `build/libs/primeva-<version>.jar`.
